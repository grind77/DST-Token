# Devnet Solana Token (DST)

An official SPL token deployed on the Solana Devnet for Web3 development, smart contract interaction, and infrastructure testing purposes.

## Token Specifications

- **Name:** Devnet Solana Token
- **Symbol:** DST
- **Network:** Solana Devnet
- **Token Standard:** SPL Token (Metaplex Metadata Standard)
- **Decimals:** 9

## Purpose

This repository hosts the official metadata and assets for the `DST` token. The token is designed exclusively for:
- Testing liquidity pool initialization on automated market makers (AMMs) like Raydium Devnet.
- Simulating decentralized exchange (DEX) swaps and portfolio tracking in developer environments.
- Verifying Phantom wallet metadata rendering for custom SPL tokens.

*Disclaimer: This token has no financial value and exists solely for testing and development purposes on the Solana Devnet.*
